# Zen 抽屉

适用于 macOS 13.1 及以上，支持 Apple Silicon 和 Intel。

1. 将「Zen 抽屉.app」拖到 Applications。
2. 从「应用程序」打开，首次启动自动创建 `~/.zen`。
3. 更新时退出 Zen，用新版 App 替换旧版；`~/.zen` 中的记录会保留。

无需安装 Chrome、Python、Node 或其他运行环境。应用使用 macOS 自带的 WebKit，断网可用。

本包若未使用 Developer ID 签名及苹果公证，首次打开时系统可能提示无法验证开发者；需在系统设置的「隐私与安全性」中确认打开。已公证版本按普通应用打开即可。

数据与程序分离：待办、QA、标签、设置和草稿在 `~/.zen/state.json`，附件在 `~/.zen/files`。每位 macOS 用户各有自己的目录，安装包不含制作者的个人记录。

应用运行时，可通过菜单「文件 → 在浏览器打开」访问同一份数据；退出应用后本机网页服务也会停止。窗口数据均由 `~/.zen` 保存，不依赖浏览器缓存。需要转移数据时，退出应用后复制 `.zen` 整个目录，或分别使用抽屉与 QA 的导出／导入。
